# Pick and Place Pneumatic System Programming

## 📌 Project Overview

This project implements an automated pick-and-place system using Arduino programming, pneumatic actuators, conveyor belts, and sensors. The system performs sequential material handling by coordinating conveyor movement, suction-based picking, pneumatic cylinder operations, and gripper control.

Sensor feedback is used to control the operating sequence, enabling automated object transfer between different stages of the system.

## ✨ Features

- Automated control of three conveyor stages.
- Pneumatic cylinder and rodless actuator control.
- Suction-based object picking and gripper operation.
- Sensor-based position detection and sequence control.
- Indicator lights for system status.
- State-based automation using Arduino programming.

## 🛠️ Technologies Used

- **Programming:** Arduino C/C++
- **Controller:** Arduino-compatible microcontroller
- **Automation:** Pneumatic actuators and conveyor systems
- **Sensors:** Digital position and object detection sensors

## ⚙️ How It Works

The system detects objects using sensors and controls the conveyors to transport them through the process. Pneumatic actuators, suction, and the gripper perform the programmed pick-and-place operations. Once the sequence is complete, the system returns to its initial state for the next cycle.

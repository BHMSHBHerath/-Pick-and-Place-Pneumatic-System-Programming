## 📌 Overview

This project demonstrates an automated material-handling system controlled by an Arduino-compatible microcontroller. It uses three conveyor stages, pneumatic cylinders, a rodless actuator, suction, and a gripper to perform sequential pick-and-place operations.

Digital sensors provide position feedback to coordinate conveyor movement and pneumatic actuator sequences.

## ✨ Features

- Automated control of three conveyor stages.
- Pneumatic cylinder and rodless actuator operation.
- Suction-based picking and gripper control.
- Sensor-based position detection.
- Sequential state-based automation.
- Red, green, and orange status indicators.

## 🛠️ Technologies Used

- **Programming:** Arduino C/C++
- **Controller:** Arduino-compatible microcontroller
- **Automation:** Pneumatic actuators and conveyor systems
- **Sensors:** Digital object and cylinder position sensors
